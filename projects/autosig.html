01Overview

An autonomous trading system where agents manage a Solana treasury through a multi-agent consensus loop, built for the Agentic Wallets challenge run by Superteam Nigeria.

Four agents run in sequence on a fixed interval: one reads live market data, one proposes a trade, one grades the proposal, and one signs and submits it.

02How it is built

  • A proposal has to clear three independent gates before anything reaches the chain: hard limits that no model can override, deterministic policy checks, and a second model acting as an independent reviewer.
  • The reviewer is a separate agent from the proposer, so a single bad generation cannot approve itself.
  • An adversarial test suite verifies the guardrails hold when the proposing agent is actively trying to defeat them.
  • Real chain, real market data, no simulated balances in the execution path.
