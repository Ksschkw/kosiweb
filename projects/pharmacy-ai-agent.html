Pharmacy AI Agent

Prescription processing and inventory system. PaddleOCR extracts text from a photograph of a prescription, an LLM structures that text into validated fields and corrects what OCR got wrong, and the result feeds multi-tenant inventory with demand forecasting.

OCR LLM FastAPI Healthcare
Code

01Overview

A prescription processing system for pharmacies. A photograph of a prescription goes in; structured, validated medication data comes out.

Optical character recognition extracts the raw text, and a language model structures it into fields and corrects what recognition got wrong, which is the failure mode that matters on handwriting.

02How it is built

  • Multi-tenant inventory, so separate pharmacies keep separate stock.
  • Demand forecasting on top of dispensing history, aimed at ordering rather than reporting.
  • Validation sits between recognition and storage, so a misread does not silently become a record.
