Bubblemaps Bot

Token analysis bot that pulls holder-cluster data from Bubblemaps, renders the bubble map, and reports concentration risk and market context on demand.

Telegram Crypto
Code Bot

01Overview

A Telegram bot that analyses a token's holder structure using Bubblemaps data, renders the bubble map, and reports concentration risk.

The point is to answer whether a small number of wallets control a token, without the user opening a block explorer.

02How it is built

  • Holder cluster analysis, so connected wallets are treated as one position.
  • Risk assessment reported alongside the map rather than left to interpretation.
  • Written up as a case study alongside the code.
