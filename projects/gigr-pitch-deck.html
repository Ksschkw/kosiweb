01Overview

An animated single-page pitch deck for Gigr, written in plain browser modules with Three.js and no framework or bundler.

Nine full-screen slides run on a step-based reveal engine over a live 3D background, with bloom post-processing and transitions that behave the same going forwards and backwards.

02How it is built

  • Navigation loops, so the deck can be driven with a clicker without hitting a dead end.
  • Content reveals a step at a time, which keeps attention on the point being made.
  • Keyboard, scroll, swipe and click all drive the same state machine.
  • No build step: the repository is the deployed artefact.
