01Overview

A multi-tenant backend for healthcare organisations such as hospitals, clinics and diagnostic laboratories, covering patient records, test requests and results.

The standout piece is the permission model, which borrows its shape from AWS IAM: atomic permissions compose into permission sets, and permission sets compose into roles.

02How it is built

  • Tenant isolation between facilities is structural rather than a convention, so a clinic cannot reach another clinic's records.
  • Authorization is data rather than hardcoded checks, so a facility can define what a role means without a code change.
  • Records use soft deletes, which keeps an auditable history instead of destroying it.
  • Credentials are hashed with Argon2.
