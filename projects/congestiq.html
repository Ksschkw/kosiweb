01Overview

A simulation research platform that asks whether multi-agent reinforcement learning can learn better TCP congestion control than the established algorithms.

The work runs entirely inside ns-3 rather than modifying a live kernel, so every experiment starts from an identical controlled environment and an untrained policy cannot damage a real network.

02How it is built

  • Agents learn to trade throughput against fairness per flow instead of applying one fixed loss-based rule.
  • Behaviour is measured against the mainstream congestion control algorithms under the same conditions.
  • Simulation traces are captured with netanim, so a result can be watched rather than only read as a number.
  • Reproducibility is the point of the simulator choice: any experiment can be re-run and compared.
