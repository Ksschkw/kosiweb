01Overview

Two halves of one platform for a content creator: a public editorial site, and a private dashboard that lets the owner rewrite copy, change colours, upload media and reorder work without touching code.

The requirement was concrete. The person using it does not write code, so every piece of content and presentation had to be reachable from the dashboard.

02How it is built

  • A public site designed to read as editorial rather than as a template.
  • A private dashboard covering copy, palette, media and ordering.
  • Media hosted on a delivery network with server-side upload handling.
  • Runs entirely on free tiers of the hosting, database and media services.
