Commit-time gatekeeper that catches documentation drift before it lands. Code Watch v0.4.0

01Overview

A commit-time gatekeeper that stops documentation from drifting away from the code it describes. It watches what a commit actually changes, detects when a structural change is not reflected in the Markdown docs, and either blocks the commit or rewrites the affected documentation to match.

Stale documentation becomes a build failure rather than a promise to fix it later.

02How it is built

  • Detects structural change, including function signatures, class methods and exported types, rather than comparing prose.
  • Ships three ways: a standalone CLI, a pre-commit hook, and a GitHub Action, so the check follows the workflow a team already has.
  • Can anchor each documentation-sync check to Solana, producing an immutable record that the docs matched the code at the moment of a commit.
  • Version 0.4.0 is the current release, and the walkthrough is on YouTube.
