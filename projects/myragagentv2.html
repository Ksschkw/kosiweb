RAG Agents
Code

01Overview

A retrieval agent built on the kssrag framework, written to exercise the published package in real use rather than in a test harness.

It rewrites a question before searching and declines to answer when the retrieved context does not support one.

02How it is built

  • Serves as the working proof that the packaged framework behaves the same way when installed from the index.
  • Carries a rejection path, which matters more than the answering path for a retrieval system.
