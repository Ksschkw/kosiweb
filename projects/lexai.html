LexAI

Question answering over the Nigerian Constitution with a hybrid retriever that pairs FAISS vector search against BM25 keyword scoring, so exact statutory phrasing and paraphrased questions both retrieve the right passage.

RAG Legal Tech FAISS
Code

01Overview

A legal assistant that answers questions about the Nigerian Constitution, aimed at people who need an answer and do not have a lawyer to hand.

Retrieval is hybrid on purpose: vector search over embeddings is paired with keyword scoring, so exact statutory phrasing and paraphrased questions both find the right passage.

02How it is built

  • Hybrid FAISS and BM25 retrieval, because statute text is full of precise phrases that pure vector search blurs.
  • Answers are grounded in retrieved passages rather than generated from memory.
  • Built to run on modest hosting, so the cost of answering a question stays close to zero.
