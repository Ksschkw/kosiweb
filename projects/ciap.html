01Overview

An analytics platform for the African creator economy. It aggregates cross-platform metrics into an influence score, then exposes creator discovery and campaign planning to the agencies and brands doing the hiring.

The first integration is YouTube analytics, covering engagement, reach and audience demographics.

02How it is built

  • Influence scoring is heuristic and documented, so a ranking can be explained rather than asserted.
  • A normalisation layer sits between the platforms, so adding a source does not change the scoring code.
  • Authentication uses short-lived sessions in HTTP-only cookies.
  • Built as a typed API with a separate front end.
